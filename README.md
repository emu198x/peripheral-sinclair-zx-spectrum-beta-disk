# peripheral-sinclair-zx-spectrum-beta-disk

Technology Research's Beta 128 disk interface and TR-DOS paging.

| Crate | Registry |
|---|---|
| [`emu198x-peripheral-sinclair-zx-spectrum-beta-disk`](crates/emu198x-peripheral-sinclair-zx-spectrum-beta-disk) | [crates.io](https://crates.io/crates/emu198x-peripheral-sinclair-zx-spectrum-beta-disk) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Pentagon 128 and Scorpion ZS-256.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
